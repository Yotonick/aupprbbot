# schedule-cal — расписание в календаре телефона

Cloudflare Worker, который отдаёт расписание группы как календарь (.ics) и страницу «Подписаться».
Данные берёт с сайта (`schedule-full.json` + `notices.json`), поэтому отмены и переносы из админки
попадают в календарь сами. Адрес сайта наружу не показывается.

## Установка (один раз, ~10 минут, через сайт Cloudflare)

0. **Сначала примите (Merge) Pull Request** с календарём: воркеру нужен файл `schedule-full.json` на сайте.
   Это безопасно — пока функция не включена в админке, кнопку видите только вы.
1. Зайдите на **dash.cloudflare.com** → слева **Workers & Pages** → **Create** → **Create Worker**
   (может называться «Start with Hello World»).
2. Имя воркера: **`schedule-cal`** — ровно так, иначе адрес не совпадёт с приложением.
   Нажмите **Deploy**.
3. Нажмите **Edit code**. Удалите весь код в редакторе, вставьте целиком содержимое файла
   `worker/schedule-cal.js` из этого репозитория. Нажмите **Deploy** (справа вверху).
4. Проверьте в браузере:
   - `https://schedule-cal.yotonick.workers.dev/` → должно быть «schedule-cal работает»;
   - `https://schedule-cal.yotonick.workers.dev/cal/1d2401uir.ics` → скачается/откроется календарь;
   - `https://schedule-cal.yotonick.workers.dev/sub/1d2401uir` → страница «Расписание в календарь».

> Если адрес у вас получился другим (например, другое имя поддомена), поменяйте строку
> `const CAL_API='…'` в `schedule.html`.

## Проверка перед запуском для всех

Пока в админке выключено «Подписка на календарь → Включить для всех», кнопку в приложении
видите **только вы** (аккаунт `@yotonick` в Telegram). Порядок:

1. Откройте мини-апп → Настройки → «📅 Добавить в календарь» → «Подписаться» → в Safari подтвердите.
2. Проверьте пары в «Календаре» и в виджете. Отмените какую-нибудь будущую пару в админке —
   примерно через час (или сразу после «Настройки → Календарь → Учётные записи → обновить»)
   она станет «❌ ОТМЕНА».
3. Дайте ссылку `https://schedule-cal.yotonick.workers.dev/sub/1d2401uir` другу с Android.
4. Всё хорошо → админка → вкладка «Объявления» → «Включить для всех» → «Опубликовать».
   По желанию — объявление с галочкой «Кнопка «📅 Добавить в календарь»».

## Если что-то пошло не так

| Что | Как |
|---|---|
| Спрятать кнопку у всех | Админка → «Выключить для всех» → «Опубликовать». Подписки, которые уже есть, продолжат работать |
| Выключить функцию совсем | В `schedule.html` сделать `const CAL_API='';` |
| Вернуть сайт полностью как было | GitHub → Pull Request с календарём → кнопка **Revert**. Или ветка `backup-before-calendar` — это точная копия сайта до изменений |
| Сломался воркер | Он отдельный: на приложение и расписание не влияет. Можно просто удалить его в Cloudflare |
| Сайт недоступен | Воркер отдаёт последнюю удачную копию, а если её нет — ошибку. Пустой календарь он не отдаёт никогда, поэтому пары у людей не пропадут |

## Настройки в ссылке

`/cal/<группа>.ics?f=s|f|c&e=1&kch=0&fk=0&cnl=0&a=10`
— вид названия (АХД · Лекция / полное / АХД), эмодзи, скрыть кураторский час / физкультуру /
отменённые, напоминание за N минут. Всё это выбирается в окне в приложении, руками собирать не нужно.
